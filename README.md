# Keystone Delivery Service Management System

A full-stack Delivery Service Management System developed using Spring Boot and React.

## Tech Stack

- Java 17
- Spring Boot
- Spring Security
- PostgreSQL
- React
- Material UI
- Axios
- Maven

## Features

- Authentication & Role-based Access
- Customer Management
- Site Management
- Work Order Management
- Technician Assignment
- Work Order Tracking
- SLA Tracking
- Inventory Management
- Reports & Analytics
- CSV / Excel / PDF Export

## Run Backend

```bash
mvn spring-boot:run
```

## Run Frontend

```bash
npm install
npm run dev
```
